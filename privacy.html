Privacy Policy

Trading P&L Journal

This application is a personal trading-journal tool. It is intended to store information entered by the user, such as trade dates, results, P&L, notes, and screenshots.

Google account and Drive data

If Google Sign-In and Google Drive backup are enabled, the application may access the Google account information and Drive application data that the user authorizes. This access is used only to provide sign-in and backup/restore functionality for the user's journal.

Data sharing

We do not sell users' journal data or use it for advertising.

User control

The user can stop using the application and revoke its Google access through their Google Account security settings.

Contact

For privacy questions, contact the application owner using the developer contact email shown in the Google OAuth configuration.
